# Day Trade Scanner V2 — Web/Mobile

Este pacote contém a versão V2 pronta para ser publicada em um serviço de hospedagem
compatível com Python/Streamlit e acessada pelo navegador do iPhone.

## Como será o uso
1. Publicar este projeto em um serviço de hospedagem.
2. O serviço fornecerá um endereço HTTPS.
3. No iPhone, abrir esse endereço no Safari.
4. Opcionalmente, adicionar à Tela de Início para abrir como um aplicativo.

## Arquivos
- app.py — scanner V2
- requirements.txt — dependências
- Procfile — comando de inicialização para serviços compatíveis
- runtime.txt — versão do Python
- README.md — documentação

Observação: este projeto é um scanner de pesquisa/teste. Ele não envia ordens automaticamente para Exnova ou Quotex.
